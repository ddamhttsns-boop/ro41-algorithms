Трассировка рекурсивной функции

1. Базовый случай и шаг рекурсии

Базовый случай — `n <= 1`. При выполнении этого условия функция возвращает число `1` и больше не вызывает саму себя.

Шаг рекурсии — `return n * F(n - 1);`. На каждом вызове значение `n` уменьшается на единицу, а результат умножается на текущее значение.

2. Трассировка F(4)

При вызове `F(4)` функция последовательно вызывает себя с меньшими значениями, пока не дойдёт до базового случая.

Вызовы вниз по стеку:

`F(4) → F(3) → F(2) → F(1)`

После достижения `F(1)` начинается возврат результатов.

| Вызов | Глубина | Возвращает |
|---|---:|---:|
| F(4) | 0 | 24 |
| F(3) | 1 | 6 |
| F(2) | 2 | 2 |
| F(1) | 3 | 1 |

Вычисления при возврате:

- F(1) = 1
- F(2) = 2 × 1 = 2
- F(3) = 3 × 2 = 6
- F(4) = 4 × 6 = 24

**Ответ: F(4) = 24.**

3. Что произойдёт при вызове F(-1)?

Если заменить условие `n <= 1` на `n == 1`, функция перестанет останавливаться при отрицательных значениях.

При вызове `F(-1)` получится следующая последовательность:

`F(-1) → F(-2) → F(-3) → F(-4) → ...`

Значение `n` будет постоянно уменьшаться, поэтому условие `n == 1` никогда не выполнится.

Функция продолжит создавать новые вызовы, пока не закончится доступная память стека.

В результате возникнет ошибка **StackOverflowException** — переполнение стека вызовов.

Таким образом, условие `n <= 1` необходимо, чтобы функция завершалась также при нулевых и отрицательных значениях.
