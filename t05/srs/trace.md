Разбор рекурсивной функции F(n)

1. Условия работы функции

Функция использует два случая:

- Условие остановки: `n <= 1`. Если оно выполняется, результатом будет единица.
- Рекурсивный вызов: `n * F(n - 1)`. Функция вызывает себя с числом на единицу меньше и умножает полученный результат на текущее значение.

2. Пошаговый разбор F(4)

Сначала программа переходит от большего аргумента к меньшему:

`F(4) → F(3) → F(2) → F(1)`

На значении 1 выполнение рекурсии прекращается. Затем результаты вычисляются в обратном направлении.

| Вызов | Глубина стека | Результат |
|---|---:|---:|
| F(4) | 0 | 24 |
| F(3) | 1 | 6 |
| F(2) | 2 | 2 |
| F(1) | 3 | 1 |

Порядок получения результатов:

1. `F(1) = 1`
2. `F(2) = 2 * 1 = 2`
3. `F(3) = 3 * 2 = 6`
4. `F(4) = 4 * 6 = 24`

Итоговое значение функции равно **24**.

3. Поведение функции при F(-1)

Рассмотрим изменение условия остановки с `n <= 1` на `n == 1`.

Если передать функции отрицательное число -1, условие остановки не сработает. Каждый следующий вызов будет получать ещё меньшее число:

`F(-1) → F(-2) → F(-3) → F(-4) → ...`

До значения 1 программа не дойдёт, поэтому рекурсивные вызовы не завершатся обычным способом.

В итоге стек вызовов переполнится. В C# это может привести к ошибке `StackOverflowException`.

Вывод: правильное условие остановки важно для завершения рекурсии. В исходной функции проверка `n <= 1` предотвращает бесконечное углубление при отрицательных аргументах.
