## 1. Псевдокод
1. Ввод целого числа n (n >= 0).
2. Если n < 0, вывод ошибки и завершение.
3. Если n == 0, то count = 1, sum = 0.
4. Иначе: пока n > 0, вычисляем последнюю цифру (n % 10), прибавляем к сумме, увеличиваем счетчик и делим n на 10.
5. Вывод результатов (count, sum).
