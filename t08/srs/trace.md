Лабораторный анализ строковых типов и памяти в CSharp

По первому заданию. Строка s равна "  Ахметов Ерлан;85 ". Метод Trim убирает пробелы с обоих концов, в итоге получается "Ахметов Ерлан;85". После вызова Split с разделителем точка с запятой строка делится на две части. Первая часть это имя Ахметов Ерлан длиной 13 символов, а вторая часть это число 85 длиной 2 символа.

По второму заданию. Строка line это Иванов Пётр;70;85;x. После сплита получаем массив из четырех элементов. Для индекса ноль Иванов Пётр метод int TryParse возвращает false, а переменная out получает значение ноль, так как это текст. Для индекса один и два значения 70 и 85 метод возвращает true, а переменные out получают числа 70 и 85. Для индекса три строка x возвращает false и ноль в out, потому что буквы нельзя перевести в число. Если функция проверяет только числовые ячейки индексы один и два, то результат будет true, а если попадет текст или x, то вернется false.

По третьему заданию. Обычные строки в CSharp неизменяемы. В цикле s плюс равно i на каждом шаге в памяти создается новый объект. Для четырех шагов и пустой строки всего образуется пять разных строковых объектов. Класс StringBuilder работает иначе, он использует один внутренний буфер и метод Append меняет его без создания новых объектов, поэтому в памяти остается всего один объект StringBuilder.

По четвертому заданию. Строки обладают свойством неизменяемости. Метод ToUpper не меняет старый объект в памяти, а создает новый с заглавными буквами и возвращает его. Если не сделать присваивание переменной вроде s равно s ToUpper, то исходная переменная так и останется указывать на старый неизмененный объект.
