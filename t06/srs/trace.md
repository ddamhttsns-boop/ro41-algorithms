Трассировка операций с массивом

Исходный массив: `a = {4, 1, 7, 3, 9}`.

1. Циклический сдвиг влево

Сохраняем `a[0]` в `buffer = 4`, затем сдвигаем остальные элементы влево.

| Шаг | i | Массив |
|---|---:|---|
| Начало | — | {4, 1, 7, 3, 9} |
| 1 | 0 | {1, 1, 7, 3, 9} |
| 2 | 1 | {1, 7, 7, 3, 9} |
| 3 | 2 | {1, 7, 3, 3, 9} |
| 4 | 3 | {1, 7, 3, 9, 9} |
| Конец | — | {1, 7, 3, 9, 4} |

2. Разворот массива

Меняем симметричные элементы местами.

| Шаг | i | Обмен | Массив |
|---|---:|---|---|
| Начало | — | — | {4, 1, 7, 3, 9} |
| 1 | 0 | 4 и 9 | {9, 1, 7, 3, 4} |
| 2 | 1 | 1 и 3 | {9, 3, 7, 1, 4} |

Выполнено 2 обмена.

Цикл идёт до `n / 2`, потому что после обмена первой половины со второй массив уже развёрнут. Средний элемент при нечётной длине остаётся на месте.

3. Поиск минимума

При `min = 0` алгоритм ошибается на массиве `{4, 1, 7, 3, 9}`, так как все элементы больше нуля.

Исправление:

```csharp
int min = a[0];

for (int i = 1; i < a.Length; i++)
{
    if (a[i] < min)
        min = a[i];
}
```

Минимальный элемент исходного массива: **1**.
